# deploy/runpod — DVAS all-in-one RunPod deployment

Full plan: [`docs/DVAS_RunPod_Deployment_Plan.md`](docs/DVAS_RunPod_Deployment_Plan.md) ·
What was implemented on `runpod-v1` and why: [`/context_runpodv1.md`](../../context_runpodv1.md)

One container on one RunPod L40S pod runs every cloud service as a supervisord
program: nginx :80 (only public port), dashboard backend, ingest API, Keycloak,
7 analyzers + analytics gateway, PostgreSQL 16, Valkey, MinIO. State lives on the
network volume under `/workspace/dvas`.

```
deploy/runpod/
├── Dockerfile, Dockerfile.dockerignore   all-in-one image (Phase 3)
├── requirements/{ai,anpr,backend,ingest,gateway}.txt   one venv each
├── etc/{supervisord,nginx,valkey,postgresql,pg_hba}.conf
├── bin/
│   ├── dvas-init.sh        entrypoint: volume, secrets, env, first-boot DB, → supervisord
│   ├── gen-secrets.sh      first boot: /workspace/dvas/secrets/{dvas.env,users.json}
│   ├── db-bootstrap.sh     first boot: roles, databases, schema (baseline dump or migrations)
│   ├── db-migrate.sh       apply SQL files once each (table deploy_migrations)
│   ├── keycloak-start.sh   Keycloak 24 (optimized), optional realm import
│   ├── dvas-bootstrap.sh   every boot: Keycloak setup, MinIO buckets+ILM, migrations
│   ├── backup-loop.sh      nightly pg_dump (02:00 IST), disk guard
│   ├── healthcheck.sh, dvas-ctl, wait-for.sh
├── tools/
│   ├── collect_versions.sh, check_build_host.sh            Phase 0
│   ├── stage_models.sh, dump_baseline_schema.sh,
│   │   export_realm.sh, sanitize_realm.py,
│   │   check_zero_byte_py.sh, install_git_hooks.sh          Phase 1
│   └── build_image.sh, run_local_test.sh, freeze_image_versions.sh   Phase 3
├── db/            baseline dumps (Phase 1.3) + migrations/{analytics,dashboard}/
├── keycloak/      realm-template.json (sanitised, Phase 1.5)
├── env/           dvas.env.example, local-compose.env.example
├── tests/         pytest: sanitize_realm, setup_keycloak users, gen-secrets
└── models.sha256  weight manifest (generated by tools/stage_models.sh)
```

## Quick path (from the repo root, on the Ubuntu build server)

```bash
deploy/runpod/tools/check_build_host.sh          # Phase 0
deploy/runpod/tools/collect_versions.sh          # Phase 0 — needs the local stack running
deploy/runpod/tools/install_git_hooks.sh         # Phase 1.2
deploy/runpod/tools/dump_baseline_schema.sh      # Phase 1.3 — review, then commit
deploy/runpod/tools/stage_models.sh              # Phase 1.4 — commit models.sha256
deploy/runpod/tools/export_realm.sh              # Phase 1.5 — commit realm-template.json only
BASE_IMAGE=runpod/pytorch:<tag> deploy/runpod/tools/build_image.sh            # Phase 3.6
deploy/runpod/tools/run_local_test.sh ghcr.io/quantumweaveintelligence/dvas-runpod:<tag>
```

Tests: `python -m pytest deploy/runpod/tests -q`
